# Little Town

## Product
An offline classroom exploration game for elementary and pre-intermediate English learners. One student gives directions; the other moves the tourist. It is intended to become part of a larger collection of teacher tools.

## Current delivered behaviour
- Full-screen town and suburbs maps with colourful detailed raster scenery.
- Arrow-key / WASD movement, small on-screen direction buttons, panning and zoom.
- Place-label toggle, reset on the current map, and a picture phrase book with optional Russian translations.
- Three town bus routes with different next stops.
- Fictional train-ticket offers at both stations; travel to the suburbs and back to town.
- Suburban family-house labels use plural possessives, such as The Johnsons’ house.
- Mall parking lot, farm, forest, field, hill, mountain, lake, theme park, bay and harbor.
- No timer, score or speech checker.

## Workflow
One focused feature or related group of changes per task. Read the backlog, agree on the intended behaviour, implement, run appropriate checks, review the playable export, and save a version before starting another substantial feature.

## Next phase
Establish the repository and reusable coding environment first. The reported path bugs are deferred until the user requests fixes. Future features, packaging and a multi-game launcher remain design decisions, not part of this import.
